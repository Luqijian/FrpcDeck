# FrpcDeck v3.1.0

本版本新增 WebUI 内置文档中心，并刷新所有界面截图。

![文档中心](https://raw.githubusercontent.com/Luqijian/FrpcDeck/main/docs/screenshots/docs.png)

## 内置文档中心

登录后侧边栏新增「文档」页面：

- 分类展示全部文档：使用文档、项目说明、开发与项目、更新日志
- 支持文档搜索
- Markdown 渲染：标题、表格、代码块、引用、图片
- 文档间链接直接在面板内跳转
- 截图从 `/api/docs/assets/` 读取，随镜像发布
- 包含 README、部署/配置/API/架构/故障排查/开发指南、安全策略、贡献指南和历史版本说明

文档随 Docker 镜像一起构建，不需要额外的文档服务或网络访问。

## 截图更新

登录、概览、代理、代理编辑器、连接配置、访问器、运行日志、实例、文档中心、移动端、首次改密等截图均已更新到 v3.1.0 界面。

## 镜像

```text
ghcr.io/luqijian/frpcdeck:latest
ghcr.io/luqijian/frpcdeck:3.1.0
ghcr.io/luqijian/frpcdeck:v3.1.0
```

支持 `linux/amd64` 与 `linux/arm64`。

## 升级

```bash
docker compose pull
docker compose up -d
```

使用固定版本时把 `.env` 中的 `IMAGE_TAG` 改为 `3.1.0`。刷新页面后可以从侧边栏进入「文档」。
