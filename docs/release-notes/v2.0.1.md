# FrpcDeck v2.0.1

本版本集中修复代理数量较多时，代理列表和编辑器打开卡顿的问题。

## 性能改进

- 代理列表改为 **每页 20 条**，配置有 47 条代理时不再一次渲染全部行。
- 缓存配置“是否有未应用更改”的深比较，避免每次渲染重复序列化整个配置。
- 代理行和状态统计使用缓存与 `v-memo`，离屏行使用 `content-visibility`。
- 编辑器的折叠面板改为按需挂载，只有展开时才创建表单内容。
- 打开编辑器时先绘制抽屉，再在下一帧挂载表单，打开动画不再等待大表单渲染。
- 移除页面级淡入淡出，缩短抽屉动画并减少背景模糊开销。

## 兼容性

- 代理、批量端口、导入导出和认证流程的行为不变。
- 代理列表超过 20 条时显示分页控件；搜索和筛选会回到第 1 页。
- 新建代理后会自动跳到包含新代理的页面。

## 镜像

```text
ghcr.io/luqijian/frpcdeck:latest
ghcr.io/luqijian/frpcdeck:2.0.1
ghcr.io/luqijian/frpcdeck:v2.0.1
```

支持 `linux/amd64` 与 `linux/arm64`。

## 升级

```bash
docker compose pull
docker compose up -d
```

使用固定版本时把 `.env` 中的 `IMAGE_TAG` 改为 `2.0.1`。
