# FrpcDeck v2.1.1

## 修复

- 优化登录页在宽屏、高 DPI 分辨率下的布局。
- 登录页两栏内容现在被限制在居中的 **1360px** 画布内，不再分别贴住屏幕左右边缘。
- 品牌介绍与登录卡片之间保持稳定间距，左右留白更均衡。
- 1440px、1834px、2898px 宽度下均验证无横向滚动，登录卡片保持居中。

![宽屏登录页](https://raw.githubusercontent.com/Luqijian/FrpcDeck/main/docs/screenshots/login-wide.png)

## 镜像

```text
ghcr.io/luqijian/frpcdeck:latest
ghcr.io/luqijian/frpcdeck:2.1.1
ghcr.io/luqijian/frpcdeck:v2.1.1
```

支持 `linux/amd64` 与 `linux/arm64`。

## 升级

```bash
docker compose pull
docker compose up -d
```

刷新登录页即可看到新的居中布局。
