# FrpcDeck v2.0.0

本版本重做管理员账户初始化与密码存储方式，避免密码通过环境变量或 `frpc.toml` 泄漏。

![首次登录强制修改密码](https://raw.githubusercontent.com/Luqijian/FrpcDeck/main/docs/screenshots/auth-forced-change.png)

## 重要变化

- **不再使用 `FRPC_WEBUI_PASSWORD` / `FRPC_WEBUI_USERNAME`**。
- 首次启动自动生成随机管理员密码，只打印一次到容器日志：

```bash
docker compose logs frpcdeck | grep 初始密码
```

- 首次登录强制修改用户名和密码，未完成前无法访问面板其他接口。
- 用户名和密码都可以在「设置 → 管理员账户」中修改。
- 管理员密码只以 scrypt 哈希保存在 `data/auth.json`，不会写入 `frpc.toml`。
- frpc 管理接口密码使用 `FRPCDECK_ADMIN_PASSWORD` 环境模板注入，`frpc.toml` 中只显示占位符。
- 旧版环境变量管理的账户首次登录会被要求修改密码。

![管理员账户设置](https://raw.githubusercontent.com/Luqijian/FrpcDeck/main/docs/screenshots/auth-settings.png)

## 忘记密码

停止容器，删除 `data/auth.json`，重新启动：

```bash
docker compose stop frpcdeck
rm data/auth.json
docker compose up -d
docker compose logs frpcdeck | grep 初始密码
```

代理配置、frps 凭据与备份保存在其他文件中，不会丢失。

## 镜像

```text
ghcr.io/luqijian/frpcdeck:latest
ghcr.io/luqijian/frpcdeck:2.0.0
ghcr.io/luqijian/frpcdeck:v2.0.0
```

支持 `linux/amd64` 与 `linux/arm64`。

## 升级

```bash
git pull
docker compose pull
docker compose up -d
```

如果使用固定版本，把 `.env` 中的 `IMAGE_TAG` 改为 `2.0.0`。升级后请登录并修改初始/旧密码。

完整变更见 [CHANGELOG](https://github.com/Luqijian/FrpcDeck/blob/main/CHANGELOG.md)。
