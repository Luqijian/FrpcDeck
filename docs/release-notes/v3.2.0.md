# FrpcDeck v3.2.0

本版本新增流量与连接监控。

![流量监控](https://raw.githubusercontent.com/Luqijian/FrpcDeck/main/docs/screenshots/monitor.png)

## 监控功能

frpc 的本地管理接口只提供代理状态，不提供流量统计。FrpcDeck 通过可选的 **frps Dashboard API** 读取：

- 今日入站 / 出站流量
- 当前入站 / 出站速率
- 活跃连接数
- frpc 客户端数量
- 每个代理的今日流量和连接数

## 使用方式

在 frps 配置中开启 Dashboard：

```toml
webServer.addr = "0.0.0.0"
webServer.port = 7500
webServer.user = "admin"
webServer.password = "change-me"
```

然后在 FrpcDeck 的 **设置 → frps 流量监控** 中启用并填写地址、用户名和密码。地址留空时会尝试 `http://<frps地址>:7500`。

每个实例独立配置；面板侧边栏新增「监控」页面，概览也开始显示今日流量、实时速度和连接数。

## 性能

- 默认每 15 秒采样一次
- 未启用时不会向 frps 发起任何请求
- 监控页面读取缓存快照
- 只查询当前实例涉及的代理类型
- 历史数据限制为 60 个采样点

## 升级

```bash
docker compose pull
docker compose up -d
```

升级后刷新页面，在「设置」中配置 frps Dashboard 即可。
