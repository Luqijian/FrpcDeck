# FrpcDeck v3.0.0

本版本支持在一个 FrpcDeck 中管理多个独立的 frpc 实例，每个实例可以连接不同的 frps。

![实例管理](https://raw.githubusercontent.com/Luqijian/FrpcDeck/main/docs/screenshots/instances.png)

## 新增

- 实例管理页：新建、重命名、切换和删除实例
- 顶部栏实例选择器，切换后代理、访问器、连接配置、日志、备份和运行状态全部切换到对应实例
- 每个实例拥有独立的：
  - frpc 进程与运行状态
  - `config.json` / `frpc.toml`
  - 代理与访问器
  - 运行日志
  - 配置备份
  - 自动启动/自动重启设置
  - 管理接口端口与随机密码
- 新建实例时自动分配不同的本地管理端口，避免多进程冲突
- 启动时按各实例的自动启动设置启动 frpc

## 数据迁移

升级后会自动把旧的单实例数据迁移到 `instances/default/`：

```text
data/
├─ auth.json                 # 全局认证
├─ session.key               # 全局会话密钥
├─ instances.json
└─ instances/
   ├─ default/
   │  ├─ config.json
   │  ├─ frpc.toml
   │  ├─ settings.json
   │  └─ backups/
   └─ inst-xxxx/
```

- 原有代理、批量端口、访问器、备份和 frps 配置都保留在「默认实例」中
- 登录密码与会话密钥不变
- 删除实例时数据移动到 `instances/.deleted/`，不会立即物理删除

## 镜像

```text
ghcr.io/luqijian/frpcdeck:latest
ghcr.io/luqijian/frpcdeck:3.0.0
ghcr.io/luqijian/frpcdeck:v3.0.0
```

支持 `linux/amd64` 与 `linux/arm64`。

## 升级

```bash
docker compose pull
docker compose up -d
```

如果你固定了版本，把 `.env` 中的 `IMAGE_TAG` 改为 `3.0.0`。升级后打开「实例」页面即可新增第二个 frpc。
