# FrpcDeck v3.1.1

本版本只更新部署文档，镜像与数据格式不变。

## 部署不再需要克隆仓库

部署指南现在直接给出可复制的：

- bridge 网络 `compose.yaml`
- host 网络 `compose.yaml`
- `.env`

用户只需新建两个文件，然后执行：

```bash
docker compose pull
docker compose up -d
docker compose logs frpcdeck | grep 初始密码
```

不再需要 `git clone`、`cp .env.example` 或保留源码目录。升级也不再需要 `git pull`。

README、README.en 和 WebUI 内置文档同步更新。

## 镜像

```text
ghcr.io/luqijian/frpcdeck:latest
ghcr.io/luqijian/frpcdeck:3.1.1
ghcr.io/luqijian/frpcdeck:v3.1.1
```

## 升级

```bash
docker compose pull
docker compose up -d
```

已有 `data/` 目录和 frpc 实例会自动保留。
