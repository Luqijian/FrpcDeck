# FrpcDeck v2.0.2

## 修复

- 修复概览页「代理总数」卡片缺少图标的问题。
- 同时修复顶部隧道信息中「N 个代理」小图标缺失。
- 原因是 `Waypoints` 图标组件被模板引用但未导入，现已补齐。

## 镜像

```text
ghcr.io/luqijian/frpcdeck:latest
ghcr.io/luqijian/frpcdeck:2.0.2
ghcr.io/luqijian/frpcdeck:v2.0.2
```

支持 `linux/amd64` 与 `linux/arm64`。

## 升级

```bash
docker compose pull
docker compose up -d
```

刷新浏览器后，概览页「代理总数」左侧会显示蓝色路由图标。
