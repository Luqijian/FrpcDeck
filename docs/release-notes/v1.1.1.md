# FrpcDeck v1.1.1

这是一个小补丁版本，修复版本号显示并完善镜像发布流程。

## 修复

- `/api/health`、首屏 Bootstrap 和设置页显示的版本号现在来自 `package.json`，不再硬编码为 `1.0.0`。
- 推送 `v*` 标签时，容器工作流会在构建后把 `latest` 和 `main` 同步到该版本镜像，避免标签镜像已更新而默认标签仍停留在旧版本。

## 镜像

```text
ghcr.io/luqijian/frpcdeck:latest
ghcr.io/luqijian/frpcdeck:1.1.1
ghcr.io/luqijian/frpcdeck:v1.1.1
```

支持 `linux/amd64` 与 `linux/arm64`，公开拉取。

## 升级

```bash
git pull
docker compose pull
docker compose up -d
```

如果使用固定版本，把 `.env` 中的 `IMAGE_TAG` 改为 `1.1.1`。

完整变更见 [CHANGELOG](https://github.com/Luqijian/FrpcDeck/blob/main/CHANGELOG.md)。
