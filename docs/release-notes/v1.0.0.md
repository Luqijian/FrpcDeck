# FrpcDeck v1.0.0

首个公开版本：为 frpc 打造的可视化配置与运行管理面板。

![FrpcDeck dashboard](https://raw.githubusercontent.com/Luqijian/FrpcDeck/main/docs/screenshots/dashboard.png)

## 核心能力

- **完整的 frpc 配置覆盖**：客户端连接、Token / OIDC、传输、TLS、QUIC、日志、管理接口、元数据，以及 TCP / UDP / HTTP / HTTPS / TCPMUX / STCP / SUDP / XTCP 全部代理类型和 10 种插件。
- **frpc 原生校验**：应用前执行 `frpc verify`，失败不会写入运行文件。
- **实时状态**：读取 frpc 管理 API，展示连接、代理状态、PID、版本、运行时长和实际远程端口。
- **实时日志**：SSE 日志流、搜索、级别过滤、暂停、下载与文件日志跟随。
- **移动端优先**：底部导航、抽屉表单和悬浮保存栏，320px 宽度可用。
- **安全**：scrypt 密码哈希、签名 HttpOnly 会话、登录限流、CSRF、CSP、0600 敏感文件。
- **备份与迁移**：自动备份最近 30 份，支持 TOML / YAML / JSON / INI 导入并保留未知字段。
- **单镜像部署**：前端、Node 服务与 frpc 打包在同一个 Docker 镜像中。

## Docker 快速开始

```bash
git clone https://github.com/Luqijian/FrpcDeck.git
cd FrpcDeck

cp .env.example .env
# 设置强密码
docker compose up -d --build
```

打开 `http://<服务器IP>:8080`。

Linux 上如果 frpc 需要直接访问宿主机的 `127.0.0.1`：

```bash
docker compose -f compose.host.yaml up -d --build
```
