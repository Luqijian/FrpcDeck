# FrpcDeck v1.1.0

本版本加入 **Go 模板配置模式**，并正式提供 GHCR 多架构公开镜像。

![模板模式](https://raw.githubusercontent.com/Luqijian/FrpcDeck/main/docs/screenshots/template.png)

## 新特性

### Go 模板模式

- 兼容 frp v0.56+ 的 Go template，包括 `range` 与 `parseNumberRangePair`。
- 导入模板后 **原样保留，不展开循环**；应用时由 frpc 自己渲染。
- 模板未声明 `[webServer]` 时自动追加管理接口，保证实时状态可用。
- 连接页提供模板编辑器、校验、TOML 预览和应用操作。
- 代理页展示 frpc 运行时生成的代理，只读；数量和状态在启动后出现。
- 支持退出模板模式并恢复导入前的结构化配置。

### 容器镜像

公开多架构镜像：

```text
ghcr.io/luqijian/frpcdeck:latest
ghcr.io/luqijian/frpcdeck:1.1.0
ghcr.io/luqijian/frpcdeck:main
```

支持 `linux/amd64` 与 `linux/arm64`，无需登录即可拉取。

## Docker 快速开始

```bash
git clone https://github.com/Luqijian/FrpcDeck.git
cd FrpcDeck

cp .env.example .env
# 设置强密码
docker compose pull
docker compose up -d
```

打开 `http://<服务器IP>:8080`。

Linux 上如果 frpc 需要直接访问宿主机的 `127.0.0.1`：

```bash
docker compose -f compose.host.yaml pull
docker compose -f compose.host.yaml up -d
```

## 从 1.0.0 升级

没有数据格式迁移。更新镜像并重建容器即可：

```bash
git pull
docker compose pull
docker compose up -d
```

现有结构化配置、模板配置、备份和认证数据都会保留。模板配置会在 `config.json` 中保存为 `rawTemplate`，仍包含 token 等敏感信息，请按密钥保护 `data/`。

完整变更见 [CHANGELOG](https://github.com/Luqijian/FrpcDeck/blob/main/CHANGELOG.md)。

FrpcDeck 与 fatedier/frp 没有官方关联。frp 遵循 Apache-2.0，FrpcDeck 遵循 MIT。
