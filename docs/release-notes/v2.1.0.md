# FrpcDeck v2.1.0

本版本增加代理列表每页行数选择，以及代理编辑器的显示位置选择。

## 每页行数可选

代理列表底部新增「每页」选择：

- 10 / 20 / 30 / 50 / 100 条
- 选择结果保存在当前浏览器
- 切换每页行数后自动回到第 1 页
- 搜索、筛选仍会重置到第 1 页

## 编辑器位置可选

代理编辑器支持两种布局：

- **右侧抽屉**：保留代理列表上下文，适合快速编辑
- **中间弹窗**：更聚焦的编辑视图，适合大屏和长表单

切换方式：

- 代理页工具栏右侧的布局图标按钮
- **设置 → 外观 → 代理编辑器位置**

选择会保存在当前浏览器，并同时应用于新建、编辑和复制代理。

![中间弹窗编辑器](https://raw.githubusercontent.com/Luqijian/FrpcDeck/main/docs/screenshots/editor-modal.png)

## 镜像

```text
ghcr.io/luqijian/frpcdeck:latest
ghcr.io/luqijian/frpcdeck:2.1.0
ghcr.io/luqijian/frpcdeck:v2.1.0
```

支持 `linux/amd64` 与 `linux/arm64`。

## 升级

```bash
docker compose pull
docker compose up -d
```

使用固定版本时把 `.env` 中的 `IMAGE_TAG` 改为 `2.1.0`。
