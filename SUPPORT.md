# Support

- **Documentation**: start at [docs/README.md](docs/README.md).
- **Troubleshooting**: [docs/troubleshooting.md](docs/troubleshooting.md).
- **Bug reports**: use the GitHub bug report template and include versions, deployment mode and redacted logs.
- **Feature requests**: open a feature request issue describing the use case.
- **Questions**: open an issue with the `question` label or start a GitHub Discussion if enabled.
- **Security issues**: do **not** open a public issue; follow [SECURITY.md](SECURITY.md).

FrpcDeck is a volunteer project and support is best effort. When asking for help, redact:

- frps token / OIDC secrets
- proxy `secretKey` values
- certificate contents and private paths if sensitive
- public IP addresses and domains if they should not be public
